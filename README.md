# Помощник подбора: телевизоры — прототип

Демонстрация для руководства: продавец ведёт разговор с покупателем, помощник подсказывает вопросы, принимает короткую голосовую выжимку продавца и подбирает 3–5 телевизоров в наличии с объяснением «почему подходит» и «в чём компромисс».

> ⚠️ Каталог, бренды, цены и остатки **вымышленные**. Прототип запускается в Google Colab, то есть в облаке Google. Для демо это допустимо, для пилота с реальными данными — только собственный сервер.

## Что показать директору (3 минуты)

1. Выберите магазин слева. Нажмите ответы: **Игры (консоль)** → **2–3 м** → **до 120 тыс.** Подборка обновляется сразу.
2. Нажмите микрофон и скажите: *«шестьдесят пять дюймов, комната солнечная, до ста тысяч»*. Справа, в панели «Под капотом», видно: распознанный текст, какие условия модель нашла, какие отброшены проверкой, время каждого шага.
3. Снимите лишнее условие крестиком на чипе.
4. Отметьте «Сравнить» у двух моделей — появится таблица с выделенным лучшим значением.
5. Скажите что-то невозможное, например *«восемьдесят пять дюймов до сорока тысяч»* — помощник честно скажет, какое условие мешает, и предложит ближайшие варианты с названным компромиссом.
6. Нажмите итог консультации — он попадёт в журнал (слева внизу).

## Как устроено

```
Голос продавца ──► GigaAM-v3 (речь → текст)
Текст выжимки ──► малая модель Qwen2.5 (текст → условия JSON) ──► проверка ──┐
                  правила-регулярки (запасной разбор) ────────────────────────┤
Кнопки ──────────────────────────────────────────────────────────────────────┴─► условия
Условия + каталог + остатки ──► правила подбора ──► 3–5 моделей, «почему», «компромисс», сравнение
```

Модель **не выбирает товар** и не пишет тексты покупателю. Каждое условие, которое она нашла, проверяется: допустимый ли это параметр, допустимое ли значение и есть ли цитата из исходной фразы. Не прошло — отбрасывается (видно в панели «Под капотом»). Если модель ошиблась или недоступна, условия достают правила, и консультация продолжается.

| Файл | Что внутри |
|---|---|
| `app.py` | Интерфейс Streamlit |
| `core/rules.py` | Вопросы, подбор, объяснения, «нет подходящих», сравнение |
| `core/parser.py` | Разбор выжимки: модель + проверка + правила |
| `core/asr.py` | Распознавание речи: GigaAM-v3, запасной Whisper-small |
| `core/config.py` | Настройки через переменные окружения |
| `core/prefetch.py` | Предварительное скачивание моделей |
| `data/tv_catalog.csv` | Вымышленный каталог: 30 телевизоров, остатки по 3 магазинам и складу |
| `colab_launch.ipynb` | Запуск в Colab с публичной HTTPS-ссылкой |
| `tests/` | Тесты логики (`python -m pytest -q`) |

## Запуск в Google Colab

1. Загрузите эту папку в свой репозиторий на GitHub (например, `tv-assistant-demo`).
2. Откройте `colab_launch.ipynb` в Colab: *Файл → Открыть блокнот → GitHub* → ваш репозиторий.
3. *Среда выполнения → Сменить среду выполнения → T4 GPU*.
4. В ячейке 1 впишите адрес репозитория, затем *Выполнить все*.
5. В последней ячейке появится ссылка `https://….trycloudflare.com`. Откройте её сами один раз заранее — при первом открытии модели загружаются в память.

Ссылка работает, пока открыт ноутбук. Бесплатный Colab отключается после простоя, поэтому запускайте за 15–20 минут до показа.

## Запуск на своём компьютере

```bash
pip install torch torchaudio            # CPU-версии достаточно
pip install -r requirements.txt
pip install "git+https://github.com/salute-developers/GigaAM.git"
# нужен ffmpeg в PATH
streamlit run app.py
```

Микрофон в браузере работает на `http://localhost` и на `https://`-адресах.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Варианты |
|---|---|---|
| `PARSER` | `llm` | `rules` — без языковой модели, только правила |
| `LLM_MODEL` | `Qwen/Qwen2.5-1.5B-Instruct` на видеокарте, `Qwen/Qwen2.5-0.5B-Instruct` на процессоре | любая чат-модель Hugging Face |
| `ASR_BACKEND` | `gigaam` | `whisper`, `none` |
| `GIGAAM_MODEL` | `v3_e2e_rnnt` | `v3_e2e_ctc` (быстрее) |

Самый лёгкий режим для очень слабой машины: `PARSER=rules ASR_BACKEND=none` — работает без моделей, выжимка вводится текстом.

## Ограничения прототипа

- Время распознавания и разбора на T4 и на процессоре не замерено — оно показывается в панели «Под капотом» при каждом запросе.
- Запись голоса — до 24 секунд (короткий режим GigaAM).
- Журнал итогов пишется в `logs/events.csv` внутри сессии Colab и пропадает при её закрытии.
- Модели: GigaAM-v3 — лицензия MIT, Qwen2.5 — Apache 2.0.
